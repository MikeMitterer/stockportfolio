# Fragen beim Testen

> Ephemerer Capture-Buffer — hier notiert man Gedanken/Fragen **mitten im Testen**,
> ohne den Flow zu verlassen. Kein Backlog: diese Datei **tendiert gegen leer**.
>
> Jeder Eintrag löst zeitnah auf zu genau einem von:
> - **sofort erledigt** → abhaken + 1 Zeile Ergebnis, dann entfernen
> - **GitHub-Issue** → `→ #NN`, dann entfernen
> - **beantwortet** → Antwort steht durable woanders (Commit/Doku/Issue) → löschen
>
> Merksatz: Tickets akkumulieren (in `solved/`), Fragen **drainieren** (nach GitHub / raus).
